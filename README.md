# 値動きウォッチ フェーズ1試作(実データ版)

「株価確認ツール要件定義書 v0.7」のフェーズ1(実データを使った試作)に対応する、
Pythonの学習も兼ねたシンプルなプログラムです。

yfinance(米国版Yahoo Finance経由のライブラリ)から日経平均株価・NASDAQ総合指数・
組み込み済み12社の株価データを取得し、変化率(%)の折れ線グラフを1枚表示します。

コードには初心者向けにコメントを多めに書いています。慣れてきたら
`config.py` の銘柄リストを書き換えて、いろいろ試してみてください。

**開発の経緯(参考)**: 最初はstooq.comというサイトから直接データを取得していましたが、
実際に動かしたところ、stooq側の「プログラムからの自動アクセスをブロックする対策」に
引っかかり、安定して取得できないことが分かりました。そこで、株価データ取得用の
Pythonライブラリとして広く使われている「yfinance」に切り替えています。
yfinanceはAPIキーなどの登録が不要です。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `config.py` | 設定(追跡する銘柄一覧・取得期間)をまとめたファイル |
| `fetch_data.py` | yfinance経由でデータを取得し、`data/`フォルダにCSV保存する |
| `plot_chart.py` | `data/`フォルダのCSVを読み込み、グラフを表示・保存する |
| `main.py` | 上記2つをまとめて実行する入り口のファイル |
| `requirements.txt` | 必要なライブラリの一覧(pipでまとめてインストールする用) |
| `data/` | 取得したCSVファイルが保存されるフォルダ(自動作成・GitHubには上げない) |
| `chart.png` | 実行後に自動保存されるグラフ画像(GitHubには上げない) |
| `.env.example` / `.env` / `.gitignore` | 現在は未使用ですが、将来ニュースAPIなど秘密の値が必要な機能を追加したときのために残しています(下記コラム参照) |

## セットアップ手順

### 1. 仮想環境(venv)を作る

お使いの環境によっては、Pythonのライブラリをシステム全体に直接インストールできない
制限がかかっていることがあります。その場合に備えて、このプロジェクト専用の
「仮想環境」を作ってから進めるのが安全です。

VS Codeでこのフォルダを開き、ターミナル(メニューの「表示」→「ターミナル」)で
次のコマンドを順番に実行してください。

```
python3 -m venv venv
source venv/bin/activate
```

2つ目のコマンドを実行すると、ターミナルの行の先頭に `(venv)` と表示されます。
これが出ていれば、仮想環境が有効になっている状態です(以後、ターミナルを開き直す
たびに `source venv/bin/activate` を再実行してください)。

### 2. 必要なライブラリをインストールする

`(venv)` が表示された状態のターミナルで、次のコマンドを実行してください。

```
pip install -r requirements.txt
```

### 3. 実行する

同じターミナルで次のコマンドを実行してください。

```
python main.py
```

うまくいけば、
1. ターミナルに取得状況(成功・失敗)が表示され、
2. `data/` フォルダに各銘柄のCSVファイルが保存され、
3. 変化率(%)の折れ線グラフのウィンドウが開きます。

グラフは `chart.png` としても保存されるので、ウィンドウがうまく開かない
場合はこの画像ファイルをVS Code上でクリックして確認してください。

## それぞれのファイルを単体で動かすこともできます

```
python fetch_data.py   # データ取得だけを行う
python plot_chart.py   # (すでに取得済みのデータで)グラフ表示だけを行う
```

## このフェーズでできること・まだできないこと

要件定義書のフェーズ1は「データソースを1つ選び、基本の2指数+数社で
折れ線グラフを表示するだけの試作」と定義しています。今回のプログラムは
それに対応するもので、以下はまだ含まれていません(今後のフェーズで対応予定)。

- 銘柄の検索・追加・非表示ボタンなどのUI操作(フェーズ2〜)
- ニュース表示・用語集(フェーズ4〜5)
- ローソク足・移動平均線・出来高(フェーズ6)
- 値動き予測・売買シグナル(フェーズ7・将来機能)

これらの見た目のイメージは、先にお見せしたデザイン確認用プロトタイプ
(Artifact)で確認できます。

## うまく動かないときは

- `(venv)` がターミナルの行頭に表示されているか確認してください(消えている場合は
  `source venv/bin/activate` を再実行)。
- インターネットに接続されているか確認してください。
- 「データが取得できませんでした」が続く場合は、yfinanceのバージョンが
  古い可能性があります。次のコマンドで更新してから試してください。
  ```
  pip install --upgrade yfinance
  ```
- グラフのウィンドウが開かない場合は、`chart.png` を直接開いて確認してください。
- エラーメッセージが表示された場合は、その内容をそのまま質問してもらえれば
  一緒に確認できます。

## GitHubにpushする手順

VS Codeのターミナルで以下を実行してください(GitHub上に空のリポジトリを
先に作成しておき、その`リポジトリURL`を控えておいてください)。

```
git init
git add .
git commit -m "初回コミット: 値動きウォッチ フェーズ1試作"
git branch -M main
git remote add origin リポジトリURL
git push -u origin main
```

### pushする前に必ず確認してほしいこと

- `git status` を実行して、`venv/` フォルダや `data/` フォルダ、`chart.png` が
  リストに出てこないこと(`.gitignore` に登録済みなので、正しく動いていれば
  表示されません)
- もし何かの拍子に `.env` を作ってキーのような値を書いていた場合は、それも
  リストに出てこないことを確認してください
- もし誤って上記のいずれかを一度コミットしてしまった場合は、`.gitignore` に
  追加しただけでは消えません。その場合は先にこちらに相談してください
  (履歴からの削除にはコマンドの実行に注意が必要です)。

## コラム: `.env` / `.gitignore` の仕組みについて

今回はyfinanceに秘密のAPIキーが不要だったため、`.env`ファイルは使いませんでした。
ただし、今後のフェーズ5(ニュース表示機能)で外部のニュースAPIを使う際には、
そのAPIキーを安全に管理するために同じ仕組み(`.env`に秘密の値を書き、
`.gitignore`でGitHubへのアップロード対象から除外する)を再び使う予定です。
そのため、`.env.example` と `.gitignore` のファイルはこのまま残してあります。
