# 値動きウォッチ フェーズ1試作(実データ版)

「株価確認ツール要件定義書 v0.6」のフェーズ1(実データを使った試作)に対応する、
Pythonの学習も兼ねたシンプルなプログラムです。

stooq.com から日経平均株価・NASDAQ総合指数・組み込み済み12社の
株価データを取得し、変化率(%)の折れ線グラフを1枚表示します。

コードには初心者向けにコメントを多めに書いています。慣れてきたら
`config.py` の銘柄リストを書き換えて、いろいろ試してみてください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `config.py` | 設定(追跡する銘柄一覧・取得期間)をまとめたファイル。APIキーは`.env`から読み込む |
| `.env.example` | `.env`ファイルの見本。GitHubにpushしても問題ない中身になっている |
| `.env` | 自分のAPIキーを書く、秘密のファイル(**自分で作る。GitHubには上げない**) |
| `.gitignore` | GitHubにpushしない対象(`.env`・`data/`など)を指定するファイル |
| `fetch_data.py` | stooq.comからデータを取得し、`data/`フォルダにCSV保存する |
| `plot_chart.py` | `data/`フォルダのCSVを読み込み、グラフを表示・保存する |
| `main.py` | 上記2つをまとめて実行する入り口のファイル |
| `requirements.txt` | 必要なライブラリの一覧(pipでまとめてインストールする用) |
| `data/` | 取得したCSVファイルが保存されるフォルダ(自動作成・GitHubには上げない) |
| `chart.png` | 実行後に自動保存されるグラフ画像(GitHubには上げない) |

## セットアップ手順

### 1. 必要なライブラリをインストールする

VS Codeでこのフォルダを開き、ターミナル(メニューの「表示」→「ターミナル」)で
次のコマンドを実行してください。

```
pip install -r requirements.txt
```

### 2. stooq.comのAPIキーを取得して `.env` に設定する

stooq.comは2026年4月頃から、データ取得にAPIキーが必要になりました。
以下の手順で、自分専用のキーを取得してください(無料です)。

1. ブラウザで次のURLを開く(例:ソニーグループのページ)
   `https://stooq.com/q/d/?s=6758.jp&get_apikey`
2. 画像認証(CAPTCHA)が表示されたら解く
3. 表示された画面、またはその後にダウンロードされるCSVのURLの中にある
   `apikey=◯◯◯◯◯◯` の `◯◯◯◯◯◯` の部分をコピーする
4. この`stock-watch`フォルダの中にある `.env.example` をコピーして、
   `.env` という名前のファイルを同じ場所に作る
   (VS Codeのエクスプローラーで `.env.example` を右クリック→「コピー」→
   フォルダ内に「貼り付け」→ ファイル名を `.env` に変更、でOKです)
5. `.env` を開き、次のように自分のキーを貼り付けて保存する

   ```
   STOOQ_API_KEY=さきほどコピーしたキー
   ```

`.env` は `.gitignore` に登録されているので、あとでGitHubにpushしても
このファイルの中身(＝あなたの秘密のAPIキー)はアップロードされません。

### 3. 実行する

VS Codeのターミナルで次のコマンドを実行してください。

```
python main.py
```

うまくいけば、
1. ターミナルに取得状況(成功・失敗)が表示され、
2. `data/` フォルダに各銘柄のCSVファイルが保存され、
3. 変化率(%)の折れ線グラフのウィンドウが開きます。

グラフは `chart.png` としても保存されるので、ウィンドウがうまく開かない
場合はこの画像ファイルをVS Code上でクリックして確認してください。

## それぞれのファイルを単体で動かすこともできます

```
python fetch_data.py   # データ取得だけを行う
python plot_chart.py   # (すでに取得済みのデータで)グラフ表示だけを行う
```

## このフェーズでできること・まだできないこと

要件定義書のフェーズ1は「データソースを1つ選び、基本の2指数+数社で
折れ線グラフを表示するだけの試作」と定義しています。今回のプログラムは
それに対応するもので、以下はまだ含まれていません(今後のフェーズで対応予定)。

- 銘柄の検索・追加・非表示ボタンなどのUI操作(フェーズ2〜)
- ニュース表示・用語集(フェーズ4〜5)
- ローソク足・移動平均線・出来高(フェーズ6)
- 値動き予測・売買シグナル(フェーズ7・将来機能)

これらの見た目のイメージは、先にお見せしたデザイン確認用プロトタイプ
(Artifact)で確認できます。

## うまく動かないときは

- `.env` ファイルを作り忘れていないか、中の `STOOQ_API_KEY` が正しいか確認してください。
- インターネットに接続されているか確認してください。
- グラフのウィンドウが開かない場合は、`chart.png` を直接開いて確認してください。
- エラーメッセージが表示された場合は、その内容をそのまま質問してもらえれば
  一緒に確認できます。

## GitHubにpushする手順

このプロジェクトはすでに、秘密の情報(APIキー)がコードから分離してあり、
`.gitignore` で `.env` などが除外されるようになっているので、
そのままpushして問題ありません。VS Codeのターミナルで以下を実行してください
(GitHub上に空のリポジトリを先に作成しておき、その`リポジトリURL`を控えておいてください)。

```
git init
git add .
git commit -m "初回コミット: 値動きウォッチ フェーズ1試作"
git branch -M main
git remote add origin リポジトリURL
git push -u origin main
```

### pushする前に必ず確認してほしいこと

- `git status` を実行して、`.env` がリストに出てこないこと(緑や赤の文字で
  `.env` と表示されていたら、`.gitignore` が効いていないので pushを中断して
  ください)
- 同じ理由で、`data/` フォルダや `chart.png` もリストに出てこないこと
- もし誤って一度 `.env` をコミットしてしまった場合は、`.gitignore` に
  追加しただけでは消えません。その場合は先にこちらに相談してください
  (履歴からの削除にはコマンドの実行に注意が必要です)。
